# Security

Report a suspected vulnerability privately to **ndls11235@gmail.com**. Include the affected version, reproduction steps and any relevant redacted logs. Do not include API keys, passwords, account sessions or private user files in public issues.

Public downloads currently use unsigned MathGPT binaries. Vendor clients retain their original signatures. A hash verifies that a download matches the published file; it does not establish publisher identity or prove the absence of vulnerabilities.

The 1.8.3 branch content is an unreleased candidate. See [Code signing policy](CODE_SIGNING_POLICY.md) for the current signing status and [Privacy](docs/PRIVACY.md) for candidate network behavior.
