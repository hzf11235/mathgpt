# MathGPT 桌面版隐私说明

适用于 1.8.3 候选，更新于 2026-10-30。当前公开版本仍为 1.8.2；候选尚未发布或获得代码签名。

安装向导会显示联网说明及“自动检查更新”“自动刷新账号”选项。点击继续确认所选选项；以后可在帮助页更改。偏好单独保存在本机，不包含账号或密钥，升级时保留。静默安装不替用户作出新选择；未选择的便携版、Mac 或无头启动不执行这些自动联网操作。手动登录、刷新、检查更新和安装客户端仍可使用。

## 本机保存

账号会话和 API Key 由 Windows DPAPI 或 macOS Keychain 保护，供当前系统用户使用。安装配置、工作文件夹和下载状态保存在独立的 MathGPT 数据目录。卸载程序默认保留用户数据、工作文件和独立客户端。

## 网络请求

- 启用自动更新时，启动后向 `mathgpt.xyz` 检查更新，运行时约每六小时再次检查。更新下载与验证使用固定源、签名清单、长度和 SHA256；请求不包含 API Key、会话内容或工作文件。服务器在提供下载时仍可见网络 IP 等常规连接信息。
- 用户主动登录 MathGPT 时，程序向 MathGPT 服务验证账号、刷新余额与模型列表。启用自动刷新后，Windows 窗口运行期间约每两分钟刷新账号，Mac 在启动时刷新已保存的账号/连接。关闭自动刷新不影响用户主动刷新。用户选择的模型、分组和接入计划随账号流程与网站同步。
- 用户创建密钥、修改连接或发起模型请求时，会访问所选择的服务。输入内容、工具结果和文件内容是否发出，由所用客户端及用户任务决定；发出的内容由相应 API 服务处理。
- 用户选择安装、修复或更新独立客户端时，程序从页面标示的 MathGPT 下载源或官方厂商源下载软件。程序校验固定哈希及适用的厂商签名，不将 MathGPT 的 API Key 附加给软件下载请求。
- 本机协议适配器只监听回环地址，使用独立凭据验证。适配器不记录 API Key 或聊天正文。

## 独立客户端

Codex、Claude Code 和 DeepSeek Harness 按各自的条款与隐私政策运行。MathGPT 的 API 配置采用独立用户配置目录，与用户原有登录配置分离；不能代替厂商隐私政策，也不能保证厂商程序没有其自身网络请求。

## 系统改动与移除

用户选择配置时会创建独立配置、客户端启动入口和适用的桌面快捷方式；官方 MSIX 安装由 Windows 管理。MathGPT 不添加杀毒排除、不关闭 SmartScreen、不降低防火墙策略。可以通过系统安装应用列表卸载 MathGPT；用户数据默认保留，删除前应先备份所需账号配置和工作文件。
